# 合规边界：只读截图，不模拟输入

鸣潮使用腾讯 ACE 内核反作弊，官方打击外挂/作弊/宏脚本。社区未见纯截图+OCR 工具的封禁案例，但自动化（模拟输入）类工具风险面显著更高。决定：WWEchoes 的感知手段**仅限**窗口/进程枚举与画面截图（WGC/DXGI）；**明确排除**读内存、进程注入、修改游戏文件、模拟键鼠输入（含 pydirectinput 等库、低级钩子转发点击）。

悬浮窗因此定为纯展示（全窗点击穿透 + 热键仅监听不发送 RegisterHotKey），v1 不做窗内交互；这是刻意收紧，不是技术受限——未来有人提议"顺手加个点击功能"时，先推翻本 ADR 再动手。
