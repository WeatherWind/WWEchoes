# 截图素材清单（Windows 会话采集指南）

用途：`detect/`（装配页/详情面板检测、槽位选中态）与 `ocr/`（词条区 ROI、角色名区）的标注与调试基准。
放入本目录 `raw/` 子目录（`raw/` 已约定为原始截图区，标注产物另存）。

## 采集环境（所有截图必须一致）

1. **分辨率 1920×1080、16:9、无边框窗口模式**（工具的目标运行环境，非独占全屏）。
2. **PNG 无损**。禁止 JPG／禁止经聊天工具传输（会压缩失真），直接拷贝文件。
3. 截图内容 = **游戏客户区**：不含 Windows 任务栏与其他窗口，无其他窗口遮挡。
4. 显示器 **HDR 关闭**、游戏内亮度/伽马默认（HDR 会改变色彩，破坏模板匹配）。
5. 游戏内 UI 相关设置保持默认；若存在 UI 缩放选项，保持默认并在 notes 里说明。
6. 截图时**鼠标不要悬停在声骸槽位上**（悬停高亮会干扰特征；悬停态单独拍，见 B-8）。
7. 每次采集记录**游戏版本号**（UI 随版本变化，参考 IMao 项目因 UI 改版出 bug 的教训），写在 `raw/notes.md` 里一行即可。

## 命名规范

`类别-说明-编号.png`，例：`assembly-detail-c4-full-今汐-01.png`。

## A. 核心集（必拍，约 16 张）

| # | 文件名模式 | 状态 | 数量 | 用途 |
|---|---|---|---|---|
| A1 | `assembly-<角色>-NN` | 角色-声骸装配页，**未打开**任何详情面板，角色名清晰可见 | 3（不同角色） | 装配页检测特征 + 角色名 OCR 区定位 |
| A2 | `assembly-detail-c4-full-<角色>-NN` | 装配页 + **Cost4** 详情面板：强化满(+25)、5 条副词条、5 星金 | 3（不同角色） | 详情面板检测 + 词条 ROI 标注主样本 |
| A3 | `assembly-detail-c3-full-<角色>-NN` | 同上，**Cost3**，+25 满副词条 | 2 | 确认不同 Cost 面板布局一致性 |
| A4 | `assembly-detail-c1-full-<角色>-NN` | 同上，**Cost1**，+25 满副词条 | 2 | 同上 |
| A5 | `assembly-detail-slot<k>-<角色>-01`（k=1..5） | 同一角色，**第 k 个槽位**的声骸点开详情（选中/高亮态可见） | 5 | 槽位选中态特征（当前看第几件→汇总条映射） |

## B. 边界集（强烈建议，约 4 张）

| # | 文件名模式 | 状态 | 数量 | 用途 |
|---|---|---|---|---|
| B6 | `assembly-detail-c4-plus0-01` | **+0 强化**声骸详情（无副词条或极少条） | 1-2 | 词条区为空/很少时的布局（副词条数量是否影响区域位置） |
| B7 | `assembly-detail-purple4-01` | **4 星紫**声骸详情 | 1 | 稀有度颜色特征 |
| B8 | `assembly-hover-01` | 装配页，鼠标**悬停**在某槽位上（不点击） | 1 | 确认悬停高亮是否干扰页面检测 |
| B9 | `assembly-scroll-01` | 若词条区可滚动/有滚动条的状态（如存在） | 0-1 | 确认是否需要处理滚动 |

## C. 负样本集（必拍，约 6 张）——防页面检测误触发

| # | 文件名模式 | 状态 | 数量 |
|---|---|---|---|
| C10 | `neg-hud-city-01` / `neg-hud-field-01` | 游戏主界面 HUD（城里 / 野外战斗） | 2 |
| C11 | `neg-char-stats-01` | 角色属性/详情页（非声骸装配页的角色页面） | 1 |
| C12 | `neg-echo-bag-01` | 声骸背包/仓库页 | 1 |
| C13 | `neg-other-<页面名>` | 其他易混淆页面（武器、技能、角色选择列表等） | 2 |

## D. 加分项（对状态机调参非常有价值）

- **一段 30–60 秒屏录**（mp4，60fps 佳，OBS 或 Win+Alt+R 游戏栏）：
  主界面 → 打开角色菜单 → 进入装配页 → 逐个点开 5 件声骸详情 → 切换另一个角色重复 → 退出回主界面。
  用途：页面进出动画时长实测、去抖参数（confirm_count / evidence_timeout）标定。
  文件较大可不进仓库，放 `raw/video/` 并在 `.gitignore` 评估后决定（>50MB 就本地留存，Windows 会话直接用）。

## 隐私提醒

本仓库**计划公开开源**，截图会随仓库公开。装配页一般不含 UID，但主界面 HUD 可能含昵称/好友信息——敏感内容请自行打码后再提交，或在 notes.md 标注已知暴露内容。

## 采集后

Windows 会话的下一步：基于 A 集标注 `detect/roi.py` 的 ROI 常量（装配页特征区、详情面板词条区、角色名区、槽位条），用 C 集验证不误触发，再接 OCR 管线。
