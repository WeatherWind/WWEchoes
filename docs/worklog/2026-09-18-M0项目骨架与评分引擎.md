## 关键决策与发现
- 数据源选 ChenXun-123 fork（44 配置，2025-11-23）而非调研时的 CM-Edelweiss（34 配置，2025-05）：通过遍历 GitHub forks 找到；Loping151 XWUID 引擎已闭源（0 个 calc.json）不可用。
- Cost4 声骸有 2 条主词条（固定攻击 + 自选），引擎输入用显式主/副分组（与 WWUID 库街区数据「前 2 项为主」约定不同，更适合 OCR 场景）。
- 有效词条表不区分 攻击/攻击%（WWUID 同名匹配口径），引擎保留该兼容。
- Cost3 主词条「属性伤害加成」在游戏内显示为元素名（如 湮灭伤害加成），解析器按前缀归一。
