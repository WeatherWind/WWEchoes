## 关键决策与发现

- **数据源调研结论（不换源）**：全网（WWUID fork 网络 / CM-Edelweiss 源仓库 / 社区
  评分项目 / GitHub 代码搜索 / 网络搜索）均无 3.6 后 7 个新角色（爱弥斯/琳奈/达妮娅/
  清宵/莫宁/绯雪/芙露德莉斯）的权重数据；ChenXun-123 fork 的 44 角色已是全网最全。
  策略：库外角色通用权重+明确标注，上游更新后 `vendor_wwuid.py` 一键同步。
- 角色识别的来源是"XX装配中"横条（详情面板底部，左右面板并排带 y≈920-986），此前
  "装配页无角色名"的约束因此绕开——OCR ROI `DETAIL_EQUIPPED_BY` 入库。
- WGC 帧裁剪规则实测：dx=(fw-cw)//2、dy=fh-ch（窗口模式 1922×1112→裁 1,32 得
  客户区 1920×1080）；帧尺寸变化时重取几何（适配显示模式切换）。
